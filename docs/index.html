GEO measurement toolkit

geo-measure-toolkit

Measurement and judgment tooling for GEO experiments. Power / MDE inversion, six statistical lint rules, a leakage audit, prompt freezing, feature extraction, and an information-preservation gate. Pure standard library — no numpy, no scipy, no matplotlib, and no dataset shipped.

What is in the box

Reportable at all?

tools/statpower.py — inverts power / MDE. Given the number a paper reported, computes the smallest effect that design could actually have detected.

Does that null stand up?

tools/geo_stat_lint.py — six lint rules (L1–L6) over a filled-in result card: no interval, below noise, rare binary, cluster as independent, uninterpretable null, under-identified.

Did the treatment write the answer in?

tools/tautology_audit.py — leakage score L(T,Y) with four severity bands, plus the decomposition of the treatment arm's own components.

Can I rebuild the same arms?

tools/freeze_prompts.py — snapshot plus sha256 of every prompt, with --verify for later.

Is that extractor secretly a score?

tools/geo_page_features.py — candidate features only. Its self-test scans the output keys to guarantee no score, weight or grade ever appears.

Did the rewrite fabricate facts?

tools/info_gate.py — information-preservation gate G1–G9 over free text, with an optional cross-check against an upstream reference module.
